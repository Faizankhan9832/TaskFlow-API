# TaskFlow API

A task management REST API built using Node.js, Express.js, and MySQL.

## Technologies Used
- Node.js
- Express.js
- MySQL
- MySQL2
- dotenv

## Features
- Manage users
- Manage projects
- Manage tasks
- REST API endpoints
- MySQL database integration

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Faizankhan9832/TaskFlow-API.git
```

2. Install dependencies:

```bash
npm install
```

3. Create a `.env` file and configure your database credentials.

4. Start the development server:

```bash
npm run dev
```
